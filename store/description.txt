Read your T3 Code threads and reply from Pebble Time 2.

Browse Ended, Working, Snoozed and Settled threads across your linked machines. Hold Up to change category. Titles use two lines and more threads load automatically as you scroll.

Select opens a thread. Select again opens saved replies, starting with a three-line summary. Scroll up for Refresh all, Settle, Snooze and Mark unread. Replies are shown as drafts before sending. System dictation is available when supported by your phone app and speech service.

Create a new thread from the Select-button menu: choose a machine and project, dictate your request, review and confirm. T3 uses the project defaults within your watch permissions. Interrupted creation can be resumed with the same request ID. Writing access and working system dictation are required.

Paste a T3 pairing link in settings to fill the server address and code automatically, or enter them separately. One connection includes machines linked in T3. No developer-hosted relay, account or analytics. Your phone needs HTTPS access or a Tailscale VPN to your server. Read-only permissions are available. Requesting a summary sends a prompt to your agent and may use provider credits.

English by default; French selectable in settings without reconnecting. Community translations welcome on GitHub.

Time 2 only in this release. Android has been used on hardware. iPhone setup and dictation are not yet validated: please share successful setups and problems through the iPhone compatibility form on GitHub.

Requires T3 Code with MCP and OAuth pairing support. Done means completed and unread on this watch; this read state is independent of desktop T3.
