T3 for Pebble

Read T3 Code threads and reply from your Pebble Time 2. An unofficial, open-source client by G-Cyrille.

Connect your server

  1. Install the app from the Pebble Appstore or its GitHub release.
  2. Open T3 for Pebble settings in the Pebble phone app.
  3. Paste a fresh pairing link from T3 Connections into T3 address or pairing link. The address and masked code fill automatically. You can also enter them separately. Your phone needs access through HTTPS or your Tailscale VPN.
  4. Choose permissions and connect. Read-only allows reading; replies and agent-generated summaries need additional permissions.

One connection includes machines linked in T3. No developer-hosted relay is needed. Settings are bundled with the app. English is the default; choose Français and save the language to switch without pairing again.

Use the buttons

Hold Up to switch categories. Select opens a thread. In a thread, Select opens saved replies with the three-line summary selected. Scroll up to reach Refresh all, Settle, Snooze, and Mark unread. Every reply has a draft confirmation before sending. Hold Select in the thread list to open management actions.

Done means completed and unread on the watch. Finished means read. This state is independent of desktop T3. The list refreshes about every minute while open; more rows load automatically as you scroll.

Create a thread

Choose New thread in the Select-button menu, pick a machine and project, then press Select to dictate. Review the draft and confirm. T3 uses the project’s model and permission defaults within your watch authorization, and the thread opens on the watch. Writing access and system dictation are required. If confirmation is lost, choose New thread again to resume the same request.

Compatibility and feedback

Version 1.0 targets Time 2 only. Android has been used on hardware. iPhone setup and dictation are not yet validated. iPhone reports, including successful setups, are welcome.

Dictation depends on Pebble's phone app and speech provider. Accented Latin fonts are supported; other scripts need testing. T3 must support OAuth pairing and the MCP thread API.
