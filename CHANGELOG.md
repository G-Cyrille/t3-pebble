# Changelog

## 1.0.0

First public release for Pebble Time 2. English by default, French selectable without reconnecting, and community translation catalogs. Direct connection to the user's T3 server with no hosted relay.

Includes four thread categories, two-line titles, automatic pagination, periodic refresh, local unread state, shared management actions, saved replies, and system dictation. Public source, build checks, and AI-friendly issue and PR policies.
