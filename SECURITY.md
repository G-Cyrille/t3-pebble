# Security

Please report vulnerabilities privately to **oiawo.cir@gmail.com**, the project's public support address. Include the affected version, a minimal reproduction with synthetic data, and the impact. Do not post tokens, pairing codes, private conversations, or reachable private server addresses in an issue.

The latest release is the supported version. Security fixes are published as new releases. There is no paid support or guaranteed response time.

The phone stores a bearer token locally. Use the least T3 permissions needed. Forgetting a connection removes the app's saved connection and pending reply; revoke the corresponding session in T3 to invalidate server access. Revocation and token expiry are controlled by your T3 server.
